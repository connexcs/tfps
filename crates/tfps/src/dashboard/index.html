The proxy in front of this API refused the request

A server between this browser and TFPS (HAProxy, nginx, Caddy…) answered 401 and asked for its own login, not TFPS's token. Reload the page to log in to it again.

A browser sends one Authorization header, so a TFPS token entered here replaces the proxy's password login (HTTP Basic). Either leave TFPS's token_file unset and let the proxy's login guard the API, or keep both by having the proxy authenticate some other way (a client certificate or a login cookie) and pass the Authorization: Bearer header on to TFPS.
